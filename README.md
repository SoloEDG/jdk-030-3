# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

后四关另设「印花滚箱」货场：箱子六面印着花纹，推一格就沿接触棱翻一格；手里是平铺的六格箱皮，可以换折起点、逐步折起并旋转查看。收件单标出顶面花样、封条该从顶面接到哪一侧，以及背面印记。镜像拼错的箱皮折出来是反手花纹，不能冒充同一包装；同花色同印记的箱子仍要被当成两只，分别签收。

## 玩法要点

- 木踏板仍按材质认箱：木箱压上木踏板才开门，滚箱关同样适用。
- 看货面板按玩家所站的棱显示相邻三面（顶、前、右），可绕左/绕右改变观察棱；背面两面需要挪步或换棱才看得到。
- 收件单只认当前**静止朝向**：顶面花样、封条方向、背面印记三者都要对上；一只箱子只能签一张单。
- 箱子停在收货位但只是封条方向不对时，棋盘上会出现虚线箭头，指出要把哪条棱转向收货要求的方位。
- 通关成绩只在全部收件单都配上不同的箱子后才记入目录，目录里也不会提前显示成绩。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

docker compose up --build
